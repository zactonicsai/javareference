Step 1: DTO with Builder

public class DocumentDTO {
    private final String id;
    private final String name;
    private final String content;

    private DocumentDTO(Builder builder) {
        this.id = builder.id;
        this.name = builder.name;
        this.content = builder.content;
    }

    public static class Builder {
        private String id;
        private String name;
        private String content;

        public Builder id(String id) {
            this.id = id;
            return this;
        }

        public Builder name(String name) {
            this.name = name;
            return this;
        }

        public Builder content(String content) {
            this.content = content;
            return this;
        }

        public DocumentDTO build() {
            return new DocumentDTO(this);
        }
    }
}

Step 2: Service Layer

@Service
public class DocumentService {

    public DocumentDTO ingest(String name, String content) {
        return new DocumentDTO.Builder()
                .id(UUID.randomUUID().toString())
                .name(name)
                .content(content)
                .build();
    }
}

Step 3: Controller

@RestController
@RequestMapping("/docs")
public class DocumentController {

    private final DocumentService service;

    public DocumentController(DocumentService service) {
        this.service = service;
    }

    @PostMapping("/ingest")
    public DocumentDTO ingest(@RequestBody Map<String,String> req) {
        return service.ingest(req.get("name"), req.get("content"));
    }
}

Summary

Builder Pattern helps construct complex objects step-by-step. It improves readability, immutability, and flexibility. Used heavily in enterprise apps for DTO creation.

DTO Explanation

DTO holds data only. Builder allows safe object creation without large constructors.

Service Explanation

Service layer contains business logic. Builder is used here to construct DTO safely.

Controller Explanation

Controller handles HTTP requests and delegates to service.
